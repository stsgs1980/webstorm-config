# Безопасность

Правила для проекта, созданного из шаблона. Политика уязвимостей и порядок
сообщения о них - в [SECURITY.md](../SECURITY.md); здесь - правила кода.

## Секреты

- Секреты живут в `.env`, файл в `.gitignore`; в репозиторий попадает только
  [.env.example](../.env.example) с именами и плейсхолдерами.
- Секреты не попадают в логи, тексты ошибок, тесты, снимки и сообщения
  коммитов. Проверка: secret scanning и push protection включены.
- Ключи не хардкодятся и не передаются через аргументы командной строки:
  только переменные окружения процесса.

## Входные данные

- Любой внешний ввод проверяется на границе выполнения: тело запроса,
  query-параметры, формы, файлы, ответы внешних API.
- Типы TypeScript не являются проверкой: они исчезают в рантайме. Нужна явная
  валидация (zod, valibot, ручные guard-функции) и отказ с понятной ошибкой.
- Неизвестные поля отбрасываются, а не проходят дальше «как есть».

## Авторизация

- Права проверяются на сервере для каждого действия. Скрытая кнопка или
  вырезанный пункт меню защитой не являются.
- Проверяйте владение объектом, а не только факт аутентификации: пользователь
  не должен читать чужие записи по угаданному идентификатору.
- Идентификатор пользователя берётся из проверенной сессии, а не из тела
  запроса.

## Ошибки и логи

- Ошибки обрабатываются: пустой `catch`, проглатывание отказа и «тихий» `null`
  запрещены. Сохраняйте причину и контекст.
- Пользователю отдаётся нейтральное сообщение и код; подробности - в лог.
- В логах нет токенов, паролей, cookie, номеров карт и лишних персональных
  данных. Идентификатор запроса помогает связать событие с ошибкой.

## Зависимости

- `npm audit --omit=dev --audit-level=high` блокирует CI на high и critical в
  production-дереве.
- Risk принят только с записью в [SECURITY.md](../SECURITY.md): причина,
  оценка severity и план обновления.
- Новый пакет добавляется с обоснованием: что заменяет, размер, поддержка.

## Транспорт и браузер

- HTTPS обязателен; cookie - `Secure`, `HttpOnly`, `SameSite`.
- CORS настраивается списком источников, а не `*` для приватных ручек.
- Скачиваемые файлы и HTML из внешнего источника не вставляются как есть:
  нужна санитизация или текстовый контент-тип.
